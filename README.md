# Zenist Mobile: The Omnipotent Productivity Agent 🚀✨

Zenist is a premium, high-fidelity productivity application powered by an **Omnipotent Voice Assistant** that turns natural language into complex actions. Built with React Native and Expo, it features a state-of-the-art "Agentic" architecture.

![Zenist Premium UI](https://img.shields.io/badge/UI-Mesh_Gradients-blueviolet)
![Zenist AI](https://img.shields.io/badge/AI-Omnipotent_Agent-gold)

## 🌟 Key Features

### 🎙️ The Omnipotent Voice Orb
A high-fidelity "Tap-to-Talk" interface that handles everything from simple tasks to complex app navigation.
- **Natural Language Intent Extraction:** Uses Gemini 1.5 Flash to parse voice commands into structured JSON.
- **Deep App Access:** Control theme modes, search tasks, clear data, and navigate screens just by speaking.
- **Premium Mesh Gradient UI:** Dynamic, animated color blobs with high-intensity blur for a futuristic "Living AI" feel.

### 🎭 Real-Time Simulations
When the AI creates a task or updates your flow, it doesn't just happen silently. Zenist features a **Visual Simulation Overlay** that shows the AI "thinking" and "performing" the work step-by-step.

### 🔊 Voice Synthesis (TTS)
The app speaks back! Receive audible confirmations for every action taken, making the experience feel like a true companion assistant.

### 📂 Smart Task Management
- **Bento-Box Dashboard:** A clean, organized overview of your mission status and progress.
- **Subtask Intelligence:** Add multiple subtasks via voice and watch as the app auto-completes parent missions when the last subtask is checked.
- **Timeline View:** A chronologically organized flow of your upcoming missions.

## 🛠️ Technology Stack
- **Frontend:** React Native (Expo)
- **AI Brain:** Google Gemini 1.5 Flash API
- **Styling:** Custom Vanilla CSS with Expo Blur & Linear Gradients
- **Voice:** Expo Audio & Expo Speech
- **Icons:** Lucide-React-Native

## 🚀 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/destroyer929/Zenist-Mobile.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Set up Environment Variables:**
   Create a `.env` file and add your `GEMINI_API_KEY`.
4. **Run the app:**
   ```bash
   npx expo start
   ```
